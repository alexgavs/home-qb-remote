# Security policy

Security fixes target the latest released version and the main branch. Older
versions may require upgrading; no fixed response-time or support-term guarantee
is offered.

Use GitHub's **Security > Report a vulnerability** on
https://github.com/alexgavs/home-qb-remote/security/advisories/new when private
reporting is enabled. If it is unavailable, open an issue requesting a private
contact without describing an exploit or attaching sensitive data.

Include the affected version/platform, impact and a minimal reproduction using
a local fake server. Never include passwords, API keys, session cookies, private
keys, personal server URLs, torrent names or unredacted logs/screenshots.
Do not test against servers you do not own or have permission to assess.

See [privacy and trust boundaries](docs/PRIVACY.md) and
[maintenance policy](docs/MAINTENANCE.md). This client does not replace qBittorrent
server access controls, firewall rules, HTTPS or VPN protection.
