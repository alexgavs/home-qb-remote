# Home qB Remote

Открытый клиент qBittorrent на Flutter под лицензией MIT. Без рекламы,
аналитики и регистрации у разработчика. Торренты загружает ваш сервер
qBittorrent; встроенного torrent-движка нет.

Доступны несколько серверов, управление торрентами и файлами, RSS, поиск,
категории, теги, настройки, уведомления и блокировка средствами ОС.
Язык выбирается в настройках приложения или следует системе; поддерживаются
английский, русский, иврит, украинский, немецкий, французский, испанский
и арабский. Android 13+ поддерживает системный выбор языка приложения.

В текущих исходниках есть необязательный прямой поиск/добавление через Jackett
и каталог Jellyfin только для чтения. Обычный поиск плагинов и RSS выполняет
qBittorrent; прямые интеграции обращаются к своим настроенным серверам.
Настройка и ограничения: [INTEGRATIONS.md](INTEGRATIONS.md). Наличие в готовой
сборке проверяйте по release notes. Есть локальные тесты, но реальный end-to-end
с Jackett/Jellyfin пока не подтверждён. Встроенного плеера и SMB-доступа нет.

Сборки: [Releases](https://github.com/alexgavs/home-qb-remote/releases).
iOS Simulator ZIP не устанавливается на iPhone; нужна подпись Apple.
Архив macOS без подписи не является нотарифицированной сборкой.

Требования и команды: [BUILDING.md](BUILDING.md). Приватность:
[PRIVACY.md](PRIVACY.md). Обновления зависимостей проходят проверки и ревью,
а не автоматически принимаются. Полная документация: [English](../README.md).
Не публикуйте пароли, ключи и личные адреса сервера в issues.
