# Home qB Remote

לקוח qBittorrent בקוד פתוח, מבוסס Flutter וברישיון MIT. ללא פרסומות,
אנליטיקה או חשבון אצל מפתח היישום. ההורדות מתבצעות בשרת qBittorrent
שלכם; מנוע טורנטים מקומי אינו כלול.

ניתן לנהל שרתים, טורנטים וקבצים, RSS, חיפוש, קטגוריות, תגיות והתראות.
אפשר לבחור שפה בהגדרות היישום או להשתמש בשפת המערכת. השפות הנתמכות:
אנגלית, רוסית, עברית, אוקראינית, גרמנית, צרפתית, ספרדית וערבית.
עברית מוצגת מימין לשמאל. ב־Android 13 ומעלה אפשר לבחור שפה גם בהגדרות המערכת.

הורדות: [Releases](https://github.com/alexgavs/home-qb-remote/releases).
חבילת iOS Simulator אינה ניתנת להתקנה ב־iPhone; דרושים חתימה ופרופיל Apple.
חבילת macOS ללא חתימה אינה מאושרת בתהליך notarization.

הוראות בנייה: [BUILDING.md](BUILDING.md). פרטיות: [PRIVACY.md](PRIVACY.md).
עדכוני תלויות עוברים בדיקה וסקירה. התיעוד המלא זמין
[באנגלית](../README.md). אין לצרף סיסמאות, מפתחות או כתובות שרת פרטיות לדיווחים.
