# Home qB Remote

Відкритий клієнт qBittorrent на Flutter під ліцензією MIT. Без реклами,
аналітики та облікового запису розробника. Торренти завантажує ваш сервер
qBittorrent; вбудованого локального рушія немає.

Підтримуються кілька серверів, керування торрентами й файлами, RSS, пошук,
категорії, теги, сповіщення та системне блокування. Мову можна вибрати
в налаштуваннях або використовувати системну: англійська, російська, іврит,
українська, німецька, французька, іспанська та арабська.
Android 13+ також має системний вибір мови застосунку.

Збірки: [Releases](https://github.com/alexgavs/home-qb-remote/releases).
Архів iOS Simulator не встановлюється на iPhone: потрібні підпис і профіль Apple.
Непідписаний архів macOS не пройшов notarization.
