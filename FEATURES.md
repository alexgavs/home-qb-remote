# Feature coverage

See [docs/FEATURES.md](docs/FEATURES.md) for functionality, supported platforms and validation limits, and [docs/ROADMAP.md](docs/ROADMAP.md) for planned local downloads and LAN playback.

The interface supports English, Russian, Ukrainian, Hebrew, Arabic, German, French and Spanish. Language selection is available in the application; Android also exposes supported languages in app-language settings. Hebrew and Arabic use right-to-left layout. Localization and platform builds must pass the checks in [CONTRIBUTING.md](CONTRIBUTING.md) before release.
